# Тесты

Все тесты проекта лежат здесь, а не рядом с исходниками в `internal/` и `cmd/`.

Структура повторяет слои приложения (`domain`, `usecase`, `adapter`, `delivery`, `integration`).

Запуск:

```bash
go test ./tests/...
```

Пакеты тестов — внешние (`package foo_test`), чтобы проверять публичный контракт пакетов.
